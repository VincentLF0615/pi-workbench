# 白色工作台、模型选择与快捷方式图标

2026-11-15

## 界面与模型

参考 `gustavonline/pi-desktop` 的浅色配色和桌面布局思路，使用白色主区域、
浅灰侧栏、细边框、留白、灰色用户消息和独立的输入卡片。
样式参考：上游 `src/styles/tokens.css` 与 `src/styles/theme.css`。
本项目的样式与图标为自行实现。

工具栏新增明确的「选择模型」按钮，快捷键为 `Ctrl+Shift+M`。
列表直接读取 Pi 的 `get_available_models`，支持按名称、ID、服务商搜索、
按服务商筛选、刷新、当前模型标记、上下文大小和思考能力信息。
当前模型排在首位；先选择模型与该模型支持的思考强度，再点击「确定」应用，
取消不会修改会话。成功后关闭窗口，失败时显示原因。运行中的任务结束后才允许切换。
档位规则与托盘功能详见 [模型选项与托盘](model-options-and-tray.md)。

思考强度按当前模型的 `thinkingLevelMap` 展示；修复调整思考强度时错误进入
「运行中」状态的问题。选择窗口支持键盘浏览、Escape 关闭和焦点约束。
模型选择由 Pi 保存到会话中，恢复会话时沿用；不会改写 Pi 的全局模型配置。

本机主题已设为亮色，新配置也默认亮色，仍可在设置中切换其他主题。

## 图标

保留深底蓝色 π 的方向，改成无字体依赖、无阴影的统一轮廓。
`tools/make-icons.py` 同时生成界面品牌图、平台图片及七档尺寸 ICO。

Windows 快捷方式使用独立资源 `icons/pi-workbench-iso-v2.ico`，
避免继续命中旧 EXE 路径下的模糊图标缓存。
资源随安装包分发，NSIS 安装钩子会更新现有桌面和开始菜单快捷方式的图标。
