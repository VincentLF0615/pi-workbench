# Pi 官方标志的来源

Pi Workbench 是个人使用的非官方 Pi 桌面客户端，与 Pi 或 Earendil 无官方
隶属、赞助或背书关系。

本项目使用 [Pi 官方 Press Kit](https://pi.dev/press-kit) 提供的
[彩色 SVG](https://pi.dev/logo.svg)，获取日期为 2026-11-15。
源文件保存为 `apps/desktop/src/assets/pi-mark.svg`，保留原图形和配色。
`tools/make-icons.py` 从该文件导出透明背景的桌面图标，仅调整透明留白，
保证小尺寸辨识度，不改变图形比例或颜色。

图标归其相应权利人所有。项目没有主张拥有 Pi 标志，也没有将代码许可证
当作对品牌标识使用范围的额外授权。本次配置用于本机个人使用；若以后公开
分发，应重新核对届时适用的官方品牌政策及授权。

应用“设置 → 关于”提供来源说明，安装包附带 `branding-notice.txt`。
