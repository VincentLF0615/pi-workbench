# 按模型显示思考档位与托盘留驻

## 模型与思考强度

模型窗口中的点击只修改待应用选项。选好模型和思考强度后点击「确定」，
才会修改当前会话；取消、Escape 或点击遮罩关闭都不会应用选择。
顶部模型按钮的小箭头已移除。

`get_available_models` 在 Pi 返回的模型元数据上补充 `supportedThinkingLevels`。
规则与本机 Pi 1.6.0 的 `getSupportedThinkingLevels` 一致：

- 非思考模型仅支持 `off`，界面显示不支持思考的说明。
- `thinkingLevelMap` 中的 `null` 表示明确不支持；GPT-6.2 的 `off` 与 `minimal` 因而不会显示。
- 未声明的普通档位按 Pi 的默认规则处理；`xhigh`、`max` 需显式声明。
- 点击另一个模型后立即按该模型重新计算选项，不再沿用当前运行模型的档位。

例如，本机 Step 3.5 Flash 是 `low/high`，Step 3.7 Flash 是
`low/medium/high`，DeepSeek Flash 是 `off/low/high/max`。
这些选项来自本机模型目录，未按模型名称写死。

「确定」调用 `configure_model`，在同一会话锁内重新检查模型可用性、档位和
运行状态，然后依次应用模型与档位，并验证 Pi 实际返回的状态。部分应用失败
会尝试恢复原设置；若恢复失败，界面会显示原因并重新读取真实状态。
不改写 Pi 的全局模型默认配置。

## 托盘

默认点击窗口最小化按钮会隐藏到 Windows 托盘，保持窗口、会话和 Pi 进程，
运行中的任务继续。工具栏的「托盘」按钮也能手动收起。

- 点击托盘图标或菜单「打开 Pi Workbench」恢复窗口。
- 右键菜单「退出 Pi Workbench」真正退出，并回收 Pi 子进程。
- 「设置 → 最小化到托盘」可关闭自动收起，恢复普通任务栏最小化。
- 关闭窗口仍按原有行为退出；没有增加开机自启。

系统托盘初始化失败时保留普通窗口最小化，避免窗口无法恢复。
